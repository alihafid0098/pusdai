# gsk-video-generation

**PREREQUISITE:** Read `../gsk-shared/SKILL.md` for auth, global flags, and security rules.

Generate videos using AI models. Supports text-to-video and image-to-video generation.

## Usage

```bash
gsk video [options]
```

**Aliases:** `video`

## Flags

## Local File Support

Parameters that accept URLs (`--image_urls`, `--first_frame_url`, `--middle_image_url`, `--last_frame_url`, `--audio_url`, `--video_url`, `--video_urls`, `--audio_urls`) also accept local file paths. The CLI automatically uploads local files before sending to the API.

## Output File

Use `-o <path>` / `--output-file <path>` to download the generated result directly to a local file.
